## Скрапинг преподавателей РГПУ им. А. И. Герцена

### Цель
Автоматизированный сбор данных сотрудников РГПУ им. А. И. Герцена (ФИО, email, телефон) со страниц каталога `atlas.herzen.spb.ru` и формирование структурированного CSV-файла.

### Структура решения
Задание реализовано двумя независимыми способами:
- **Python + BeautifulSoup** 
- **Node.js + Puppeteer**

Оба решения имеют идентичную архитектуру: конфигурация, сбор ссылок с кэшированием в JSON, параллельный парсинг профилей, дозапись результатов в CSV.

### Принцип работы
1. **Сбор списка преподавателей.** Последовательный обход страниц `/teachers?page=1` ... `page=54`, извлечение ссылок на профили и сохранение в `teachers_links.json` для повторного использования.
2. **Параллельный парсинг профилей.** Пул из 5 воркеров одновременно обрабатывает страницы преподавателей. Данные извлекаются по смысловым признакам: ФИО — из `<h2>`, email — по наличию `@`, телефон — по префиксу `+`, `7`, `8`.
3. **Сохранение с устойчивостью к сбоям.** Результаты дозаписываются в CSV по мере готовности. При повторном запуске скрипт пропускает уже обработанные записи, что позволяет возобновлять работу после прерывания.
